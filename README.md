# 习惯打卡

单文件的习惯打卡网页：双击 `index.html` 就能用，零依赖、零构建、不联网，数据自动保存在浏览器本地。

## 快速开始

- 打开方式：双击 `index.html`（Chrome / Edge 等 Chromium 浏览器均可）。
- 首次打开会预置 3 个示例习惯：喝水 💧、运动 🏃、学习 📚，可以直接打卡，也可以删掉自己加。
- 每天打开页面点一下习惯就完成打卡，顶部显示今天完成了几项。

## 功能

- 今日打卡：点习惯整行即可打勾 / 取消。勾选状态由「今天的日期 + 当天记录」实时推导，跨天自动归零，不需要重置逻辑或定时器。
- 今日进度：显示「已完成 n / m 项」、百分比和进度条；全部完成时文案会变成一句完成提示，并压成一枚印章。
- 添加习惯：输入名称后回车或点「添加」，名称上限 20 字。
- 自动配图标：按名称匹配预设图标（喝水 → 💧、运动 → 🏃、睡前阅读 → 📖 等），共 13 个预设，也可以手动点选，未匹配时默认 ⭐。
- 删除习惯：点 × 先变成「确认删除?」，2 秒内再点一次才真正删除；只从今天移除，历史记录不受影响。
- 近 7 天：按每天的完成比例画柱状图，没打卡的日子显示为空柱，右侧给出这 7 天的累计完成项数。
- 本月热力图：周一为第一列，按当天完成比例分 5 档着色，今天用墨绿细环标记；可以往前翻看历史月份，不能翻到未来。
- 细节：习惯列表为空时有引导文案；全天完成、当天状态、跨天刷新都会自动同步。

## 数据存储

- 键名：`habit-tracker:v1`，存在浏览器 `localStorage` 里。
- 结构：

```json
{
  "version": 1,
  "habits": [{ "id": "hxxx", "name": "喝水", "emoji": "💧", "createdAt": 1790000000000 }],
  "records": { "2026-10-10": { "done": ["hxxx"], "total": 4 } }
}
```

- 日期键使用浏览器本地时区的 `YYYY-MM-DD`，刻意不用 `toISOString()`，避免时区偏移。
- `records` 只在当天真的打过卡才写入；从没打开过页面的日期在图表里显示为无记录。
- 局限：数据属于「当前浏览器 + 当前文件路径」，换浏览器、换电脑或清缓存都会丢。不做导出 / 导入，也不做云同步。

## 设计说明

- 结构：一张主表 + 两条历史区。今天的进度、习惯、添加框在同一张白纸上，用贯穿纸边的细规线分隔行；历史区只留一条顶部规线，不重复白卡和阴影。
- 配色：纸白底 + 近黑正文 + 石墨灰次要信息；墨绿只用于「完成」语义（大数字、勾、进度条、今天的日期、热力图），删除用砖红且只在二次确认时亮起。
- 版式：单一系统字体栈（拉丁优先，中文回退到苹方 / 雅黑），层级只靠字号和字重；数字统一等宽对齐，习惯行高 52px（窄屏 50px）。
- 动效：只有两处，且都由操作触发——勾选落定（方块底色 160ms、勾号 180ms）、全天完成的印章压印 280ms；`prefers-reduced-motion: reduce` 下全部关闭。
- 背景：方格纸点阵纹理（CSS 径向渐变，22px 网格，固定不随滚动移动）。
- 可访问性：整行是可聚焦的 `<button>`（回车 / 空格可切换），`aria-pressed` 反映勾选状态，键盘焦点有绿色焦点环。

## 文件结构

只有 `index.html` 一个文件（约 1200 行 / 33 KB），HTML、CSS、JS 全部内联，没有任何外链、CDN 或第三方库。

## 改样式时请保留的钩子

JS 依赖下面这些 id 和 class，重做外观时不要改名：

- id：`today-label`、`progress-top`、`progress-text`、`progress-pct`、`progress-track`、`progress-fill`、`habit-list`、`habit-empty`、`add-form`、`habit-input`、`emoji-row`、`trend-chart`、`trend-hint`、`cal-title`、`cal-week`、`cal-grid`、`cal-prev`、`cal-next`
- class：`habit`、`habit-main`、`habit-emoji`、`habit-name`、`check`、`del`、`confirming`、`done`、`emoji-btn`、`selected`、`num`、`is-done`、`bar-col`、`bar-wrap`、`bar-num`、`bar`、`bar-label`、`none`、`lv0`~`lv4`、`cell`、`blank`、`today`
- 柱状图的高度由 JS 写入 `height: calc((100% - 18px) * 比例)`，所以柱子上面显示数字的那一行必须保持 18px 行高。
- 颜色、圆角、阴影集中在 `:root` 的 CSS 变量里，换主题优先改变量。

## 本地验证

仓库里没有自动化测试脚本，界面改动用本机 Chrome 无头模式验证（流程与命令见项目 `AGENTS.md`）：

- 截图看视觉：桌面 900×1400，手机 390×1250 或 520×1400。
- 抓 DOM 校对文案与数字：例如筛出 `id="today-label"` 所在节点。
- 一个坑：`--headless=new` 会把窗口宽度下限卡在约 500px，要拿到真实的 390px 视口，需要用一个 390px 宽的 iframe 包装页面再截图。

## 明确不做的事

- 不做后端、账号、多设备同步、导出 / 导入。
- 打卡单位是「项」，不做计次目标（例如喝水 8 杯）。
- 历史只读：不支持补打卡，也不支持点开某天看明细。
- 不支持「只在工作日」之类的频率规则，每个习惯每天都可打卡。
- 只有浅色主题。

## 环境

原生 HTML / CSS / JS，无构建、无依赖，不需要 npm。建议在 Chromium 内核浏览器中打开，`file://` 下 `localStorage` 可用。
